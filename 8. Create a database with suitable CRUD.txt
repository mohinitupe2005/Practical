8. Create a database with suitable example using MongoDB and implement
a. inserting and saving document (batch insert, insert validation)
b. Removing document
c. Updating document (document replacement, using modifiers, upserts,
updating multiple documents, returning updated documents)

Step 1: Create / Select Database
use EmployeeDB

🧱 Step 2: Create Collection
db.createCollection("Employees")

🧩 (a) Inserting and Saving Documents
1️⃣ Single Insert
db.Employees.insertOne({emp_id: 1, name: "Omkar", dept: "IT", salary: 40000})

2️⃣ Batch Insert (Multiple Documents)
db.Employees.insertMany([{emp_id: 2, name: "Sakshi", dept: "HR", salary: 35000}, {emp_id: 3, name: "Rohan", dept: "Finance", salary: 50000}, {emp_id: 4, name: "Sneha", dept: "IT", salary: 28000}])

3️⃣ Insert with Validation Example (check for missing field)

(MongoDB doesn’t validate automatically unless schema is enforced — you can check manually)

db.Employees.insertOne({emp_id: 5, name: "Pooja", dept: "Sales"})  // salary missing (invalid example)

🗑️ (b) Removing Document
Delete one record (by ID)
db.Employees.deleteOne({emp_id: 3})

Delete all records from a specific department
db.Employees.deleteMany({dept: "Sales"})

✏️ (c) Updating Documents
1️⃣ Document Replacement (replaces entire document)
db.Employees.replaceOne({emp_id: 1}, {emp_id: 1, name: "Omkar Biradar", dept: "IT", salary: 45000})

2️⃣ Using Modifiers (e.g., $set, $inc)
db.Employees.updateOne({emp_id: 2}, {$set: {dept: "Admin"}})

db.Employees.updateOne({emp_id: 4}, {$inc: {salary: 2000}})

3️⃣ Upsert (update if found, otherwise insert)
db.Employees.updateOne({emp_id: 6}, {$set: {name: "Shreya", dept: "HR", salary: 32000}}, {upsert: true})

4️⃣ Update Multiple Documents
db.Employees.updateMany({dept: "IT"}, {$inc: {salary: 3000}})

5️⃣ Return Updated Document

(In MongoDB shell, findOneAndUpdate() returns updated document)

db.Employees.findOneAndUpdate({emp_id: 2}, {$inc: {salary: 1000}}, {returnNewDocument: true})
